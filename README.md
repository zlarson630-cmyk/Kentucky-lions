# Kentucky Lions Baseball

Public-facing fictional AFBL franchise publication for the Kentucky Lions.

## Website
- [Homepage](https://zlarson630-cmyk.github.io/Kentucky-lions/)
- [April 5, 2075 game recap](https://zlarson630-cmyk.github.io/Kentucky-lions/game-recap.html)

## Enable GitHub Pages (one-time)
Repository → Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

The first deployment may take a few minutes. The public URLs above work after GitHub Pages has been enabled.

## Content
The initial launch contains a homepage, four embedded artistic baseball reconstructions, a photo gallery, and a game recap (Kentucky 10, Minnesota 6, April 5, 2075). All photographs are AI-generated illustrations of fictional events, not documentary images.

## Publishing policy
The GM has authorized direct publication of completed game stories and photographs without an additional approval step. Future site updates can be committed to the main branch, which will trigger GitHub Pages deployment once enabled.

## Next iteration
Migrate to a content-driven static generator (Astro) so each game has one Markdown/JSON entry and homepage, game index, and gallery update automatically. The current initial release is static HTML.
